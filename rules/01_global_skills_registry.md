# 🧠 GLOBAL SKILLS REGISTRY (SSOT POINTER)

Antigravity automatically discovers skills from `~/.gemini/config/skills/` (junctioned to `<GLOBAL_GUIDELINES_ROOT>/skills/`).

- **On-Demand Skill Index:** The complete list of skills (name + 1-line purpose) lives in [master-orchestrator/SKILL.md](../skills/master-orchestrator/SKILL.md). Never preload unrelated skills; read **only** the `SKILL.md` file(s) required for the active task.
- **SEO Precedence (`starseo` + `seo-growth-architect`):** Use `starseo` plugin skills as primary for live SEO audits, keyword research/clustering, AI visibility (GEO), and reporting; use `seo-growth-architect` as SSOT for codebase implementation (Next.js metadata, JSON-LD Schema, CWV, GA4 DataLayer); use `semrush` plugin when Semrush-specific API data is requested.
